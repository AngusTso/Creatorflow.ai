# Revision Policy

## Included Revisions

Each standard project includes up to two rounds of revisions.

A revision round means one consolidated set of requested changes submitted by the client after receiving a draft.

## Additional Revisions

Requests beyond the included revision rounds may require an additional fee.

The creator should confirm the additional fee with the client before beginning additional revision work.

## Changes to Original Scope

A request that substantially changes the original project requirements may be treated as additional work rather than a normal revision.

The creator should discuss the change in scope and any additional fee with the client before proceeding.

## Revision Timing

Clients should provide revision requests within the review period specified in the project agreement.

If no review period has been agreed, the parties should establish a reasonable review period before work begins.
